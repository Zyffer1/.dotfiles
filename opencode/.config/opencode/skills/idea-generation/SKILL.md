# Idea Generation

## Approach

1. **Explore the baseline** — read current configs to understand what exists
2. **Research trends** — search the web for innovative dotfiles patterns, new tools
3. **Generate ideas** — 3-5 ideas per session, from quick wins to moonshots
4. **Filter** — rate each by effort (small/medium/large), impact (low/medium/high), risk (low/medium/high)
5. **Document** — write ideas to `plan.md` under a "Blue Sky" section

## Sources to check

- r/unixporn, r/commandline
- GitHub dotfiles repos (search: "dotfiles stars:>1000")
- Hacker News
- Tool-specific communities (neovim, tmux, zsh, i3)
